# PrivacyGuard AI

AI-powered personal data deletion auditing agent.

## Overview
PrivacyGuard AI analyzes user deletion requests,
tracks personal data across multiple systems,
and generates remediation and verification plans.

## Features
- Identity Resolution
- Evidence Analysis
- Policy-Based Deletion Auditing
- Remediation Planning
- Automated Verification

## Tech Stack
- Python
- AI / LLM
- Rule-Based Engine
